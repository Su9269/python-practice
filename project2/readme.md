# 台股均線交叉策略回測（2303.TW, 2023年）

## 專案動機
我會做這個小專案的動機是因為我未來有規劃想要進入金融業或是從事關工作，所以想要從比較入門、基礎的地方切入並作練習，可以在做的過程中更能了解程式碼的實際操作還有相關金融常識，並且透過分析以圖表呈現來觀察某一檔股票的表現，讓股票不再只是帳面上的數字或是天書，而是能以更清晰、更容易理解的方式呈現
資料來源為Yahoo Finance（透過yfinance套件下載），標的為2303.TW（聯電），時間範圍為2023年1月1日至2023年12月31日的日線資料，包含開盤價、收盤價、最高價、最低價與成交量。

## 策略邏輯與方法論

### MA5/MA20交叉訊號
以5日均線（短期，反應較快）與20日均線（長期，反應較穩定）的交叉關係作為進出場依據：短期均線由下往上穿越長期均線視為買進訊號（黃金交叉），反之視為賣出訊號（死亡交叉）。

### 方法論反思：兩次關鍵修正
在建構回測邏輯的過程中，發現並修正了兩個容易被忽略、但會實質影響結果正確性的問題：
**1. Lookahead Bias（前視偏誤）**
初版策略報酬率計算若未妥善處理時間順序，容易讓模型「偷看」到交易當下尚未發生的未來資訊，導致回測績效被高估、不具備實際可執行性。修正方式為在計算策略報酬率時，以`signal.shift(1)`確保每日交易僅根據前一日已確定的訊號執行，而非當日訊號。

**2. Signal 數值設計的邏輯錯誤**
初版策略以`1`代表持有、`-1`代表不持有，但在計算「策略報酬率 = 每日報酬率 × signal」時，`-1`實際上使策略呈現「反向做空」的效果（股價下跌時策略獲利），而非原先設想的「空手觀望、不參與市場漲跌」。修正後改以`1`代表持有、`0`代表空手，使`0`乘以任何報酬率皆為0，正確反映「空手不受市場漲跌影響」的邏輯。

這兩次修正皆透過手動代入實際數字驗證後發現，也再次印證了「不能只看結果是否合理，而要驗證每一步計算的邏輯是否真正符合設計初衷」的重要性。

## 參數網格搜尋
測試短期均線（5, 10, 15, 20天）與長期均線（20, 30, 60天）共12組合理組合，比較最終報酬率：

### 觀察
1. 表現最佳組合為short=5, long=30（9.10%），但仍未超越買入持有（36.26%）
2. 長期均線設定為60天時，所有短期均線搭配的報酬率皆為負值，推測是因為60天均線對趨勢反應過慢，在2023年這種持續上漲的市場中，容易導致進場時機落後、錯失早期漲幅

## 結論與侷限反思
本次回測顯示，簡單的均線交叉策略在2023年這種單邊上漲的市場環境中，難以超越單純買入持有的表現。這也反映了技術分析策略的一項常見侷限：進出場的時機成本，可能抵銷策略試圖捕捉的部分漲幅。此外，本次分析僅涵蓋單一股票、單一年度，策略在不同市場環境（例如下跌、盤整）下的表現，仍有待進一步驗證。
